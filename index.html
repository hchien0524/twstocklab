為何要自動更新

GitHub Pages是靜態，不會自動變收盤價。你現在GitHub上點【🔄一鍵更新】是前端抓官方API。另一個是後端每日自動：

1. 在 repo 建 .github/workflows/update.yml（程式碼在下面）

2. 到 Actions → Daily Price Update → Run workflow 點一下就更新 six_stock_portfolio.json

3. 每天 14:30 自動跑，1101 就會自己變 24.65

name: Daily Price Update
on:
  schedule:
    - cron: '30 6 * * 1-5'
  workflow_dispatch:
jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Fetch TWSE
        run: |
          pip install requests -q
          python official_market_fetch.py --date $(date +%F) --out./tmp || python -c "
          import requests,json; d=requests.get('https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL',timeout=20).json(); m={x['Code']:x for x in d};
          import json as js; p=js.load(open('six_stock_portfolio.json'));
          [s.__setitem__('current',float(m[s['code']]['ClosingPrice'])) for s in p['stocks'] if s['code'] in m];
          js.dump(p,open('six_stock_portfolio.json','w',encoding='utf-8'),ensure_ascii=False,indent=2)
          "
      - name: Commit
        run: |
          git config user.name "bot"; git config user.email "bot@github.com"
          git add six_stock_portfolio.json; git diff --staged --quiet || git commit -m "auto: update close"; git push
